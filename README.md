# Impacto de las redes sociales en el bienestar estudiantil

Proyecto final de Python para Ciencia de Datos, realizado por **Santiago Robatto y Lucas Giúdice**.

Analizamos la relación entre el uso de redes sociales, el sueño, el estrés, la salud mental y el rendimiento académico de estudiantes.

## Archivos

- `Proyecto_Final.ipynb`: análisis completo, código, gráficos y conclusiones.
- `Proyecto_Final_con_codigo.html`: informe exportado con código.
- `Proyecto_Final_sin_codigo.html`: informe exportado sin código.
- `Datos/Entrada/Social_media_impact_on_life.csv`: datos utilizados.

## Fuente de datos

[Impact of Social Media on Life — Harish Yadav, Kaggle](https://www.kaggle.com/datasets/harishyadav0506/impact-of-social-media-on-life).
